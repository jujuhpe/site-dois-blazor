# SiteDoisBlazor

Projeto desenvolvido para a lista de exercícios práticos de Blazor Nível 2.

## Funcionalidades

- Conversor de temperatura de Celsius para Fahrenheit.
- Calculadora de média do aluno com resultado aprovado/reprovado.
- Sorteador de números aleatórios entre 1 e 100.
- Menu lateral com navegação para todas as páginas criadas.

## Tecnologias

- .NET 10
- Blazor
- C#

## Como executar

```bash
cd SiteDoisBlazor
dotnet watch
```
